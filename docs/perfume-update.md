# メンズ香水6選の改修記録

## 追加・変更した機能

- 投稿ごとの特集一覧と詳細。カテゴリ・表紙・タイトル・商品数を表示。
- 手動表示順→実際の投稿日→番号の順に並べる構造。公開／非公開を投稿と商品で管理。
- 投稿番号・タイトル検索、ブランド・商品名検索とカテゴリ絞り込みを維持・拡張。
- 表紙1枚＋商品紹介画像6枚をそのまま掲載。新規生成・トリミング・商品画像取得は実施していない。
- 商品写真と所有者提供のSNS紹介ビジュアルを別管理。利用条件未確認の写真は表示しない。
- 黒・ダークネイビー、白、ゴールドとオレンジの配色。ロゴ・ナビ・既存URL・サンプル画面は維持。
- iPhone用の追加画面で既存商品の読み込み、ブランド・投稿日・表示順・カテゴリ・公開設定・SNS画像を編集可能に。
- リンク準備中の紹介カードを掲載できる `listed` 状態を追加。実際の購入リンクだけを販売先別に表示。
- 提供された楽天HTMLを改変せず、iframeで最初から表示する。
- UTM等の検索パラメータを書き換えず、ハッシュURLで特集へ遷移。
- 画面下のカードに軽量な表示アニメーション。動きを減らす設定に対応。

3. 実際のInstagram投稿日は未提供なので `null`。判明後に設定。
4. Amazonリンクは未提供。発行後に販売先配列へ追加可能。

## 新しい投稿を追加する方法

READMEの手順に従い、投稿・商品JSONと素材を追加する。iPhoneの追加画面でJSONを書き出してGitHubへ反映するか、Codexに番号・カテゴリ・順序・完成画像・公開仕様・発行リンクをまとめて渡す。コード全体の書き直しは不要。
